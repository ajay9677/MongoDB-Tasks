# MongoDB Basic Practice Task

## 📌 Project Overview

This project demonstrates the basic concepts of MongoDB, including database and collection creation, CRUD operations, query operators, and a real-world Library System use case.

## 🎯 Objectives

* Understand MongoDB fundamentals.
* Create databases and collections.
* Perform CRUD operations.
* Practice MongoDB query operators.
* Apply MongoDB concepts to a Library System.

## 🛠️ Technologies Used

* MongoDB
* MongoDB Shell (`mongosh`)

## 📚 Topics Covered

### 1. Database & Collection Setup

* Create the `studentDB` database.
* Create the `students` collection.

### 2. Insert Operations

* `insertOne()` — Insert a single document.
* `insertMany()` — Insert multiple documents.

### 3. Read Operations

* `find()` — Retrieve documents.
* Filter students by course, such as MERN Stack.

### 4. Update Operations

* `updateOne()` — Update a single document.
* `updateMany()` — Update multiple documents.

### 5. Delete Operations

* `deleteOne()` — Delete a document based on a condition.
* `deleteMany()` — Delete multiple documents.

### 6. Query Operators

* `$gt` — Greater than
* `$lt` — Less than
* `$in` — Match any value in a specified list
* `$and` — Match all specified conditions
* `$or` — Match at least one condition
* `$exists` — Check whether a field exists
* `$ne` — Not equal

## 📖 Real-World Use Case: Library System

A simple Library System is used to demonstrate MongoDB operations on book records.

Each book contains details such as:

* Title
* Author
* Category
* Price
* Availability

### Operations Demonstrated

* Insert book records.
* Search books by category.
* Find books based on price.
* Update book availability.
